# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todos com respeito, critique ideias e não pessoas, e aceite que discordância
técnica se resolve com evidência. Assédio, ataque pessoal e exposição de dado de terceiros não são
tolerados.

Para relatar uma conduta inadequada, use o relato privado do repositório (aba **Security** →
**Report a vulnerability**, indicando no título que é conduta) — veja [`SECURITY.md`](SECURITY.md).
